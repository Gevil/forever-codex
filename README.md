# Forever Codex - WoW Forever simulations

Spec, talent and gear comparisons for World of Warcraft: Forever, simulated with
[wowsims/forever](https://github.com/wowsims/forever) (MIT). Every entry links to the exact configuration behind
its number in the WoWSims Forever sim.

Pre-release model output, not in-game measurements: read the Caveats tab of any class page. Forever launches
4 Nov 2026 and every sim spec used here is still alpha.

Fan-made, not affiliated with Blizzard Entertainment. Item and talent tooltips/icons by
[Wowhead](https://www.wowhead.com/forever).
